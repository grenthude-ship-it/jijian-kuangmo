后台数据（admin-data.json）

下面是当前完整的后台数据，和游戏共用同一份格式。所有改动都会实时保存到本机并同步显示在这里。

同步方法：还没设置令牌，同步需要把 JSON 发给 Muse。设置令牌后（见上方「同步设置」），改完数据会自动同步到游戏，不用再手动发 JSON。
邮件字段说明（发邮件页签的新玩法）：
· tag：邮件标签，取值 奖励 / 通知 / 活动 / 补偿 / 私人定制。
· items.customPlayer：私人定制球星，包含 name（名字）、pos（位置：守门员/中场/前锋）、ab（能力值 1–120）、price（身价，单位万）、img（头像：图鉴球星 id 或 gold-star 金色星标）、tags（标签数组，最多 3 个）、note（备注）。只在发定制球星时出现；发图鉴球星时没有这个字段，照常用 items.playerId，且有 customPlayer 时 playerId 为 null。
· items.customTitle：自定义称号，没填称号时为 null。
· to = '*'：全服邮件，发给全部玩家；普通邮件的 to 是收件人用户名。
删掉的邮件、封禁记录、玩家和公告会先放进这里，不会真的消失，也不会同步到游戏。点「恢复」就能放回原来的地方（恢复后会重新同步）；只有点「彻底删除」并确认两次，才会真正删掉。
